# Project Statement

## Project Title

Bank Management System

## Problem Statement

The Bank Management System is a Python-based academic project designed to simulate basic banking operations through a command-line interface.

The purpose of the project is to provide users with a simple system where they can create a bank account, log in securely using an account number and PIN, check their balance, deposit money, withdraw money, transfer money between accounts, view transaction history, view account details, and change their PIN.

## Objective

The main objectives of this project are:

* To develop a simple banking simulation using Python.
* To demonstrate the use of functions and modular programming.
* To use dictionaries for storing account information.
* To implement input validation.
* To generate account numbers and transaction IDs.
* To implement basic banking transactions.
* To provide a simple and user-friendly command-line interface.
* To apply Python programming concepts to a practical problem.

## Scope

This project focuses on basic banking operations in an academic simulation. It does not connect to a real banking system, database, payment service, or financial institution.

All account information is stored temporarily while the Python program is running.

## Main Operations

The system provides the following operations:

1. Create a new account
2. Login
3. Check account balance
4. Deposit money
5. Withdraw money
6. Transfer money
7. View transaction history
8. View account details
9. Change PIN
10. Logout

## Technologies Used

* Python 3
* `random` module
* Command-Line Interface (CLI)

## Expected Outcome

The project demonstrates how Python can be used to build a basic banking application using fundamental programming concepts such as functions, loops, conditional statements, dictionaries, user input, validation, and random number generation.

## Academic Disclaimer

This project is created for educational purposes only. It is a simulation and does not perform real banking or financial transactions.
